## UI application execution proposal

For `ui-poc-application`, use the official Unit dependency DAG, write sets, external
dependencies, and walking-skeleton constraint to assess concurrency. When two
or more ready Units are dependency-independent and have disjoint writes,
propose stage-major Construction with official Code Generation swarm at the
normal Delivery Planning choice. Keep design reviews, approvals, state writes,
and Build and Test settlement under their existing owners. Preserve an
explicit serial or unit-major choice, and never record the proposal as approved
until the person answers the official gate.
